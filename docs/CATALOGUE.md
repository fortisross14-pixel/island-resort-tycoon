# Building catalogue

Every building has two separate ratings (agreed in Pass 1):

- **Unlock tier**: when you can build it. Tier 0 is available from the start; tiers 1–4 come from research (and scenario goals).
- **Quality class**: how premium it is, *Budget → Mid → Premium → Luxury*. Rooms use it as their room tier. Richer guests expect a higher class, and remember a venue that feels "a bit basic".

Changes from the GDD: themed restaurants move from tier 1 to **tier 2**, and tier 2 gains a new room, **Garden Bungalows**.

Status: ✅ in the game · ⏳ planned.
